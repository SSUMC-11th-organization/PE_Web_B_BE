## 트러블슈팅 기록

### CORS 설정과 인증 등록의 결합 방지

- 문제: 기존 WebConfig는 CORS_ENABLED=false일 때 설정 클래스 자체를 비활성화한다. 그 안에 인증까지 등록하면 CORS 비교 실습 중 인증도 함께 꺼질 수 있다.
- 해결: AuthConfig로 인증 인터셉터 등록을 분리했다.
- 검증: CORS 비활성화 상태에서도 GET /members/me 무토큰 요청이 AUTH401_2인지 자동 테스트한다.

### 제거한 평점 쓰기 URL의 응답

- 문제: 예전 POST /members/1/ratings가 401일 것으로 예상한 테스트가 실제 405를 받았다.
- 원인: 해당 쓰기 매핑을 제거했고 Spring은 인터셉터 실행 전 핸들러 선택 단계에서 허용하지 않는 메서드로 판단했다.
- 해결: 옛 URL은 405로 검증하고 실제 새 URL /ratings의 무토큰 요청은 401로 별도 검증했다.

### JWT 만료 유예와 실습 설명의 차이

- 문제: 워크북의 60초 clock skew를 그대로 쓰면 60초 만료 실습에서 즉시 만료가 관찰되지 않을 수 있다.
- 해결: 같은 서버가 발급/검증하는 실습에서는 만료 유예 없이 검증한다.
- 참고: https://github.com/jwtk/jjwt#accounting-for-clock-skew
